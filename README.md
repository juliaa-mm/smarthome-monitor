# SmartHome Monitor

Веб-система моніторингу домашніх IoT-пристроїв.
Курсова робота з дисципліни «Організація баз даних», КНУ імені Тараса Шевченка, ФІТ, 2026.

**Стек:** PostgreSQL 14+ · Node.js 20+ · Express 5 · React 19 · Vite · Recharts

## Структура проєкту

```
smarthome-monitor/
├── database/          SQL-скрипти: структура (01), дані (02), представлення (03)
├── server/            REST API на Node.js + Express
│   ├── src/
│   │   ├── index.js        точка входу
│   │   ├── db.js           пул з'єднань і транзакції
│   │   ├── crud.js         фабрика CRUD-маршрутів
│   │   ├── middleware/     автентифікація (JWT), обробка помилок
│   │   ├── routes/         опис таблиць, операції-транзакції, звіти, вхід
│   │   └── utils/mutex.js  м'ютекс (семафор) для одночасних запитів
│   └── scripts/init-db.js  створення та заповнення БД
└── client/            інтерфейс на React (Vite)
    └── src/
        ├── components/     каркас, таблиця, форма, універсальна CRUD-сторінка
        ├── pages/          сторінки застосунку
        └── lib/            API-клієнт, автентифікація, форматування
```

## Запуск (Windows / macOS / Linux)

1. Встановіть **PostgreSQL** (https://www.postgresql.org/download/) і **Node.js LTS** (https://nodejs.org).
2. У папці `server` скопіюйте файл `.env.example` у `.env` і вкажіть пароль користувача `postgres`,
   заданий під час встановлення PostgreSQL (`DB_PASSWORD=...`).
3. У кореневій папці проєкту виконайте:

```bash
npm run install:all   # встановлення залежностей сервера і клієнта
npm run db:init       # створення БД smarthome, таблиць, даних і представлень
npm run build         # збірка інтерфейсу
npm start             # запуск сервера
```

4. Відкрийте у браузері **http://localhost:3001**.

| Логін  | Пароль    | Роль                          |
|--------|-----------|-------------------------------|
| admin  | admin123  | Адміністратор (усі дії)       |
| viewer | viewer123 | Лише перегляд даних           |

Команда `npm run db:init` повністю перестворює таблиці, тому її можна використати,
щоб повернути базу до початкового стану перед демонстрацією.

### Режим розробки

У двох терміналах: `npm run dev:server` та `npm run dev:client`, потім відкрити http://localhost:5173
(Vite перенаправляє запити `/api` на порт 3001).

## Основні можливості

- вхід у систему з двома ролями (ADMIN / VIEWER), паролі зберігаються як bcrypt-хеші;
- головна сторінка з показниками та графіками;
- перегляд, пошук, фільтрація, сортування, додавання, редагування та видалення записів усіх таблиць;
- зміна стану пристрою та виконання сценарію автоматизації як **транзакції**
  (`BEGIN` → `UPDATE devices` → `INSERT state_history` → `INSERT events` → `COMMIT` / `ROLLBACK`);
- блокування рядка `SELECT … FOR UPDATE NOWAIT` і м'ютекс на сервері для одночасних запитів;
- звіти на основі представлень `v_room_device_states`, `v_latest_readings`, `v_events_full`, вивантаження у CSV;
- зрозумілі українські повідомлення про порушення обмежень цілісності (UNIQUE, FOREIGN KEY, CHECK).
